CurveDrive v3.1 / 入力画面からJW_CADを自動で準備

使い始める手順
1. ZIPを「すべて展開」し、Open.cmdをダブルクリックします。
2. 入力画面の「入力内容を確認する」を押し、計画と実測値を確認します。
3. 「JW_CADを自動で準備して、入力へ」を押します。その画面で待ってください。
4. 「準備できました」と出たら「次の測点を入力する」を押します。

JW_CADの起動、専用図面の作成、発進点の登録、外部変形の選択は自動です。
通常はSetup_Link.batの選択や発進点の右クリックをする必要はありません。
初回だけJW_CADが見つからないと出た場合は、JW_CADを一度起動してから
入力画面の青いボタンをもう一度押してください。場所は以後記憶します。

次の実測を入力する手順
推進延長 → 左右ズレ → 上下ズレの順に入力し、最後にEnterを押します。
上下ズレが不明なら空欄で構いません。CADへ追加後、実測点と接続線を読み戻して照合します。
JWへの逐次追加は平面です。縦断の入力は最新DXFにも保存します。
完了すると次の入力欄へ移ります。入力中の延長には直線・左カーブ・右カーブと半径を表示します。
左右ズレは計画線形の進行方向に対する直角方向です。左・上がプラス、右・下がマイナスです。

保存と次回の再開
入力はブラウザー内に保存し、開始時と実測送信時にはこのPCにもJSONとDXFを自動保存します。
入力画面を閉じても、送信した入力は残ります。次回もOpen.cmdを開いて画面の案内に従います。
JW_CADが閉じていれば、保存した入力から専用図面を新しく開いて続きを入力できます。
ブラウザーの保存が空になった場合は、このフォルダーのPC保存データを自動で読み込みます。

対象はこの入力から作成する専用の作業図面です。
既存の本番図面を開いたり、書き換えたりする機能にはしていません。
JW側で手描きした加筆は入力データに含まれません。必要な場合はJW側で別に保存してください。
過去の実測の訂正や計画変更は「入力・図面の設定を見直す」から行い、新しい作業図面を作成します。
「詳しい設定・復旧」には従来の手動方式も残しています。通常は開かなくて構いません。

保存場所（確認が必要な場合だけ）
App\Project.json：このPCに最後に保存した入力。
App\Work\作業番号\Latest.dxf：その作業の入力から作成した最新DXF。
App\Work\作業番号\Project.json：その作業の入力。
入力画面のDXF出力・JSONバックアップからもファイルを保存できます。

Open.cmdとAppフォルダーは一緒に置いてください。
黒い連携画面は使用中に閉じないでください。
古い版の黒い画面が残っている場合は、起動時に出る画面の案内に従って切り替えます。
動作対象：Windows、.NET Framework 4.x、JW_CAD。NodeやPythonなどの追加作業は不要です。
