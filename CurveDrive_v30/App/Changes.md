# v3.0

最初に押すものが分からない画面を、現在の操作を一つずつ案内する画面へ変更した。

- 最初の主ボタンは「入力内容を確認する」。初回設定と、前回からの再開を区別。
- 入力確認、DXF保存、JW_CADで開く、作業用JWWへの保存、設定用ファイルの選択、発進点の指定を画面で案内。
- 実測終点の登録と設定用BATの作成は、保存確認後に画面内で実行。手動の登録ボタンを探す操作を減らした。
- 実際の登録・対象プロセスを確認し、準備が整った場合に入力画面へ進む。
- ページを開き直しても、保存した図面名と案内の続きから再開。入力や作業フォルダーが変わった場合は古い案内を継続しない。
- 通信応答を失った場合も、既存の登録やBATを照合し、重複して登録し直さない。
- 古いBridgeが動いている場合の操作も画面に表示。
- ZIPを展開するとOpen.cmdとAppフォルダーが現れる構成。ZIP内で同名フォルダーを二重にしない。

入力する各延長に、直線・左カーブ・右カーブと半径を表示する。
入力中の行は大きな表示でも確認でき、区間の境目では両方の線形を表示する。
左右ズレが未入力でも判定し、範囲外や計画不正では古い表示を残さない。

従来の座標計算、mm/b0、JSON/CSV、排他・二重引渡し防止、計画線を削除しない方式は維持。
新しい画面案内から、Windows上の本物のEdgeとJW_CADで初回・再開・Enter反映を検証した。
検証の範囲と限界はTest.md。
