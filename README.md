# CurveDrive v2.8b

[CurveDrive_v28b.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v28b/CurveDrive_v28b.zip)

既存のカーブ推進・線形管理アプリを引き継いだ自動連携試験版です。外部変形の一覧からセッション用ファイルを探し、対象CAD/選択画面とファイル名を再確認して、既定動作を一回だけ呼びます。事前の選択操作を省きました。失敗時は段階・例外型・HRESULTをImport.logへ記録し、自動では繰り返しません。

旧HTMLでJSONバックアップを保存し、旧Bridgeを閉じ、ZIPを別フォルダーへすべて展開してOpen.cmdを起動してください。新しいDXFをテスト用JW_CAD一つで開き、実測終点登録→自動連携の準備→新しいSetup_Link.batで発進点指定→自動連携ONの順に設定します。詳しくは同梱Readme.txtを参照してください。

C#5互換コンパイルと149項目の検査が合格。模擬CADで正常引渡し・重複拒否・停止/状態保持・例外詳細の記録も確認しました。Windowsで今回の失敗が解消することや、実際の描画位置は実機での確認が必要です。引渡し済みは描画成功の保証ではありません。一つのJW_CAD、グループ0、軸角0度が対象です。既存図形の削除・実測線の置換は行いません。

公開物はソース、実行ファイル、説明書、架空サンプル、検査コードのみです。提供された図面、画像、実行ログ、Probe.txt、Check.txt、状態ファイルを含みません。mainと以前の配布ブランチは変更しません。
