# CurveDrive v2.9 確認方式

[CurveDrive_v29.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v29/CurveDrive_v29.zip)

既存アプリを引き継ぎ、日々の操作を「入力してEnter → CADの再実行を一回」に減らした試験版です。完全自動のWindows呼び出しは実機で拒否されており、この版ではCAD側の確認操作を一回残した代替方式を用意しました。完全自動が完成した版ではありません。

初回のCAD登録と毎日の開始準備を分け、登録情報と作業用JWW図面を使い続けます。初回はDXFを作業用Work.jwwとして保存してから登録します。一日の開始時は作業を開始し、CADでField_Run.batを一回選択します。その後は毎測点のDXF出力・発進点指定・ファイル選び直しを繰り返しません。終了時に同じJWW図面を保存してください。詳しくはDaily.txtとReadme.txtを参照してください。

通常画面では初回設定や調査用機能を閉じておけます。Open.cmdは同じ作業フォルダーのアプリが動いていれば入力画面だけ開き直し、他のサーバーを勝手に終了しません。CADからの手動呼出しと図形/ファイルの照合後に対象PIDを更新します。前点がない場合等はデータを捨てず停止し、既に引渡し済みの点は再出力しません。

C#5互換コンパイルと162項目の検査が合格。確認方式のブラウザ実入力と模擬CADでも7チェックが合格しました。Windows/JW_CADでの確認方式・再起動・保存後の座標維持は実機確認が必要で、本番運用の検証は未完了です。既存図形の削除・実測線の置換は行いません。

公開物はソース、実行ファイル、説明書、架空サンプル、検査コードのみです。提供された図面、画像、実行ログ、Probe.txt、Check.txt、状態ファイルを含みません。mainと以前の配布ブランチは変更しません。
