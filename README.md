# CurveDrive v3.0 — 画面で案内する版

[画面案内付きZIPをダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v30/CurveDrive_v30.zip)

ZIPを展開し、Open.cmdを開いてください。その後は画面に表示する案内に沿って進みます。
展開直後はOpen.cmdとAppフォルダーだけが表示されます。同じフォルダー名が二重になる構成をやめました。

![最初の画面](Start.png)

入力中の延長に合わせて、直線・左カーブ・右カーブと半径を表示します。区間の境界も表示します。

[入力中の表示例](Alignment.png)

計画・実測の計算と既存のデータを引き継ぎ、初回と前回からの再開を画面で案内します。
Windows上の本物のEdgeとJW_CAD 8.25a・10.03.8で、案内からの初回・再開・Enter反映を検証済みです。
利用者のWindows 11・会社の設定では未検証です。

[検証結果と条件](CurveDrive_v30/App/Test.md)
