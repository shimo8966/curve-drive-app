# CurveDrive v2.8a

[CurveDrive_v28a.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v28a/CurveDrive_v28a.zip)

外部変形の実行中にJW_CADを識別する処理を修正した自動連携試験版です。初期登録では起動元のプロセスをたどって対象CADを確認し、コールバックは実行中の可視状態やメニューに依存せず、登録済みのCAD/図面を照合します。停止理由も詳しく表示します。

旧HTMLでバックアップを保存し、旧Bridgeを閉じ、ZIPを別フォルダーへすべて展開してOpen.cmdを起動してください。新しいDXFをテスト図面として開き、実測終点登録→自動連携の準備→新しいSetup_Link.batで発進点を指定→自動連携ONの順に設定します。詳しくは同梱Readme.txtを参照してください。

C#コンパイルと131項目の検査が合格しました。識別条件と模擬CADでの検査を含みますが、Windows/JW_CADで今回の停止が解消するか、自動メニュー操作と実際の描画が正しいかは実機での確認が必要です。グループ0・軸角0度・一つのJW_CADを対象とします。引渡し済みは描画成功の保証ではありません。既存図形の削除は行わず、実測線の置換は未実装です。

公開物はソース、実行ファイル、説明書、架空サンプル、検査コードのみです。提供された図面、画像、実行ログ、Probe.txt、状態ファイルを含みません。mainと以前の配布ブランチは変更しません。
