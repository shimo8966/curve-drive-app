# CurveDrive v2.6 単位修正版

[CurveDrive_v26.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v26/CurveDrive_v26.zip)

## 開き方

1. 旧入力画面に保存したい入力があれば、JSONバックアップを保存します。
2. 古いCurveDrive/Bridgeの黒い画面をすべて閉じます。
3. ZIPを右クリックし「すべて展開」→「展開」を押します。
4. 展開したCurveDrive_v26のOpen.cmdを起動します。
5. 新しくDXFを出力し、末尾Plan_mm.dxfをJW_CADで新しいテスト図面として開きます。
6. 計画50mなら、水色の縦断水平線を測り、50000mmになることを確認してください。

旧版の50mmの図面には追加せず、終点登録は実寸確認後に行ってください。
詳細はZIP内Readme.txt。

## 公開用ZIPの内容

個人アカウント名を含む固定URLをソースから除き、実行ファイルを再ビルドしました。
同梱データは架空のサンプルです。実際の現場データ、ユーザーのバックアップ、状態/履歴、画面写真、生ログは含めていません。

Windows/JW_CADでのv2.6の取込・実寸・位置合わせはまだ試験が必要です。
PC受信や引渡しは、CADでの描画完了を意味しません。
