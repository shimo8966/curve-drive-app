# CurveDrive v2.8

[CurveDrive_v28.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v28/CurveDrive_v28.zip)

カーブ推進・線形管理アプリの自動連携試験版です。従来版を引き継ぎ、初回に図面と発進点を登録した後、HTMLのEnterからJW_CADの外部変形への引渡しを自動で行います。

旧Bridgeを閉じ、ZIPをすべて展開し、Open.cmdを起動してください。まずテスト図面で、新しいDXFの実測終点登録→自動連携の準備→Setup_Link.batで発進点指定→自動連携ONの順に設定します。詳しい手順は同梱Readme.txtを参照してください。

C#コンパイルと117項目の検査が合格。Windows/JW_CADの自動メニュー操作・実際の描画は実機での確認が必要です。グループ0・軸角0度・一つのJW_CADを対象とします。引渡し済みは描画成功の保証ではありません。既存図形の削除は行わず、実測線の置換は未実装です。v2.7を別フォルダーに残して試してください。

公開物はソース、実行ファイル、説明書、架空サンプル、検査コードのみです。提供された図面、スクリーンショット、実行ログ、Probe.txt、状態ファイルを含みません。mainと従来の配布ブランチは変更しません。
