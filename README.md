# CurveDrive v2.7 外部変形の倍率修正版

[CurveDrive_v27.zip をダウンロード](https://raw.githubusercontent.com/shimo8966/curve-drive-app/download-v27/CurveDrive_v27.zip)

## 起動と試験

1. 必要な入力は旧画面からJSONバックアップに保存します。
2. 古いCurveDrive/Bridgeの黒い画面をすべて閉じます。
3. ZIPをすべて展開し、新しいCurveDrive_v27のOpen.cmdを起動します。
4. v2.7から新しく出した末尾v27_mm.dxfのDXFを、新しいテスト図面として開きます。
5. 開いたDXFの実測終点を登録してから、次の新しい測点を追加します。

旧版で離れた点がある図面や、調査用に保存した図面へ再追加しないでください。
詳しい操作、直線サンプル試験と復旧手順はZIP内Readme.txtにあります。

## 修正内容

v2.6は実寸mmをbz（紙上寸法）で渡し、縮尺1/100では追加図形が100倍される問題がありました。
v2.7ではb0に戻し、実寸mmをそのまま渡します。100で割る補正はしません。
DXFのm→mm変換は維持しています。
旧版の引渡し状態を拒否し、新しい図面で始めるようにしました。
入力値のみを旧版から移行します。

C#コンパイル成功、自動検査95件/チェック合格。
Windows/JW_CADでのv2.7の取込・位置・偏差量は、実機での再照合が必要です。
