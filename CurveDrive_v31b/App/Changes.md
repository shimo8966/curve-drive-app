# v3.1b 一覧画面での自動選択を修正

- Windowsの表示倍率に応じて、画面位置を対象のJW_CADが使う座標へ変換してからクリックする。PC全体の表示設定は変更しない。
- 一覧が狭い場合や横スクロールしている場合は、対象行の見えている部分を選ぶ。ファイル名・選択・フォーカスの照合は維持する。
- 計画だけの保存、実測の順次追加、入力データの保存方法はv3.1aを継続する。

## v3.1a 計画だけの準備と連携処理の保護

- 着工前は実測0件で計画線を準備し、DXFとJSONを保存できる。初期表示に仮の実測値を入れない。
- 最初の実測は、0.5mなど実際に測った延長から開始できる。実測した0mの登録も受け付ける。
- 1点目は測点だけを作図する。未測定の発進点から実測線を引かず、2点目以降に実測点同士を結ぶ。
- 計画線の照合と実測点の照合を分け、準備・確認の表示を区別する。最初の実測が0mでも、計画だけの確認結果を測点の確認済み表示に流用しない。
- 任意の「深さ (m)」欄を追加。JSON・CSVに記録し、上下ズレ (mm) へは自動変換しない。
- 実測は1点ずつ送信し、前点と作業の登録を照合する。未送信の測点を飛ばした追加や重複送信を防ぐ。
- 古い作業番号の連携処理を拒否した際に、現在の別の登録を停止・上書きしないよう保護する。
- 外部変形一覧で対象ファイルの選択・フォーカスとクリック処理を確認する。準備失敗時は入力を保持し、状態確認と図面の再準備を案内する。

これらは処理上の改善であり、利用者のPCで起きたエラーの原因を一つに断定したものではない。
検証した環境と範囲はTest.mdに記載する。

## 継続する機能

- 入力画面から専用DXFを作成し、JW_CADを起動して固有の連携ファイルを選択する。
- 発進点は専用図面の印と計画基準から特定する。通常の自動方式では、初回の右クリックやJWW形式への手動保存を使わない。
- 実測追加後に平面の測点を読み戻し、2点目以降は接続線も照合する。CADの処理終了を待ってから次の処理へ進む。
- 入力JSONと最新DXFをPCへ保存し、ブラウザーの保存が空ならPC保存入力を復元する。
- 直線・左右カーブ・半径の表示、計画線形の進行方向に対する直角方向のズレ計算を維持する。
- 従来の手動方式、過去の入力の見直し、新しい専用図面の作成を保持する。

JWへの逐次追加は平面の実測点と線。上下ズレは最新DXFの縦断に反映する。
深さは記録用で、図面の高さや上下ズレの計算には使わない。
既存の本番図面の更新や、JWで手描きした加筆の自動保存は対象外。
