CurveDrive v3.1a / 計画線の準備と実測入力

最初にすること
1. ZIPを「すべて展開」し、Open.cmdをダブルクリックします。
2. 「入力内容を確認する」を押し、現場名と計画線を確認します。
3. 「JW_CADを自動で準備して、入力へ」を押し、その画面で待ちます。
4. 着工前は「計画線を保存しました（実測は未登録）」と表示されます。
   施工開始後に「施工開始：最初の実測を入力する」を押します。

着工前の保存
実測は0件のままで、計画線だけを準備・保存できます。
保存だけ行う場合は、入力確認画面の「JW_CAD用 DXFを出力」と
「現場データをバックアップ」から、DXFとJSONを保存できます。
計画線の準備のために、仮の実測点を入力する必要はありません。

施工開始後の入力
推進延長と左右ズレを入力します。上下ズレと深さは、分かる場合だけ入力します。
上下欄または深さ欄でEnterを押すと送信し、完了後に次の入力欄へ進みます。
深さも記録するときは、上下欄からTabで深さ欄へ進み、深さまで入力してからEnterを押します。
実測は測った順に1点ずつ送信し、確認済みの表示が出てから次へ進みます。
最初に測った延長から入力できます（例：0.5m）。0mは実際に測定した場合に入力します。
最初の実測は点として作図し、2点目から実測点同士を線で結びます。
入力中の延長には、直線・左カーブ・右カーブと半径を表示します。

単位と意味
左右ズレ：mm。計画線の進行方向に対して左がプラス、右がマイナスです。
上下ズレ：mm。計画から上がプラス、下がマイナスです。
深さ：m。路面から測った深さなどを、そのまま記録する別の欄です。
深さは上下ズレへ自動変換しません。不明な欄は空欄で構いません。

図面への反映
JW_CADへの逐次追加と照合は、平面の実測点と接続線です。
上下ズレは、入力から作成する最新DXFの縦断に反映します。
深さはJSON・CSVの記録用で、図面の高さには使用しません。
通常の自動方式では、外部変形の選択や発進点の右クリック、JWW形式への手動保存は不要です。

保存と再開
入力はブラウザー内に保存します。自動準備の開始時と実測送信時には、このPCにもJSONとDXFを保存します。
計画だけを保存して終了した場合も、実測0件の状態で再開できます。
次回もOpen.cmdを開き、画面の青いボタンに沿って再開します。
JW_CADが閉じていれば、保存した入力から専用図面を新しく開きます。
ブラウザーの保存が空になった場合は、このフォルダーのPC保存データを読み込みます。
過去の実測や計画を直す場合は「入力・図面の設定を見直す」で修正し、新しい作業図面を準備します。

保存場所（確認が必要な場合だけ）
App\Project.json：このPCに最後に保存した入力。
App\Work\作業番号\Latest.dxf：その作業の最新DXF。
App\Work\作業番号\Project.json：その作業の入力。

対象は、この入力から作成する専用の作業図面です。
JW側で手描きした加筆は入力データに含まれません。必要な加筆はJW側で別に保存してください。
「詳しい設定・復旧」には従来の手動方式を残しています。
準備を完了できない表示になったら、入力を保持したまま画面の復旧案内に従います。

Open.cmdとAppフォルダーは一緒に置き、使用中は黒い連携画面を閉じないでください。
初回にJW_CADが見つからないと表示された場合は、一度JW_CADを起動してから準備を確認します。
動作対象はWindows、.NET Framework 4.x、JW_CADです。通常利用にNodeやPythonの追加作業は不要です。
